12 / ERROR LOG

ERROR LOG

COBA → GAGAL → DEBUG → BELAJAR → COBA LAGI
ERROR 001 — DIDN'T WORK.
PROBLEM: Model helmet classification dilatih dengan crop kepala, tetapi inferensi dijalankan pada bounding box seluruh tubuh.
LESSON: Konsistensi antara data training dan data inference adalah fondasi, bukan detail kecil.
ERROR 002 — TRIED AGAIN.
PROBLEM: Nilai C pada Algoritma & Struktur Data 1.
LESSON: Kemampuan dibangun dari proses belajar, evaluasi, dan keberanian mencoba lagi.
ERROR 003 — WHEN THE API WORKED... BUT THE DATA DIDN'T.
PROBLEM: Request API berhasil, tidak ada error merah di console, tetapi data yang tampil di frontend tidak sesuai harapan karena struktur datanya berbeda.
LESSON: Error tidak selalu merah. Debugging bukan hanya mencari pesan error, tetapi juga memeriksa apakah data yang masuk sesuai dengan asumsi bentuk data.
